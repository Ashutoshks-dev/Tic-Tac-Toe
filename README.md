# Tic-Tac-Toe 🎮

A browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

* Two-player gameplay.
* Alternating turns between X and O.
* Automatic winner detection.
* Draw detection when all nine cells are filled without a winner.
* Reset and New Game functionality.
* Interactive game board.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open the HTML file in your browser.
3. Click a cell to make your move.
4. Take turns with the other player until someone wins or the game ends in a draw.
